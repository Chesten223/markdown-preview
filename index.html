Frequently Asked Questions

What Markdown syntax is supported?
The editor supports headers (h1–h6), bold, italic, strikethrough, links, images, unordered and ordered lists, inline code, fenced code blocks with language hints, blockquotes, horizontal rules, and tables. It covers the most common Markdown features used in documentation and content writing.
Is my data stored or sent anywhere?
No. All processing happens entirely in your browser using JavaScript. Nothing is sent to any server, no cookies are set, and no tracking scripts are loaded. You can even use the tool offline after the initial page load.
Can I use this for GitHub README files?
Yes. The Markdown flavor rendered here is closely aligned with GitHub Flavored Markdown. Use the README template as a starting point, then copy the raw Markdown directly into your repository's README.md file.
